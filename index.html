Quick Start

Run this in a terminal on the machine with your SDR. It asks which decoder to install and sets up feeding to Airframes.

curl -sSL https://install.airframes.sh/installer | bash

Know what you want? Name the decoder (acarsdec, dumpvdl2, dumphfdl, vdlm2dec, all or adsb) and skip the questions:

curl -sSL https://install.airframes.sh/installer | bash -s -- -y acarsdec
ADS-B? Airframes doesn't ingest ADS-B itself, but the installer can feed it to our partners Airplanes.Live and Plane Watch: pick ADS-B in the menu, or run | bash -s -- adsb. On a PiAware or other ADS-B box it feeds them from the decoder you already run. To feed Airframes ACARS, VDL2 or HFDL as well, add a second SDR.

Supports Linux, macOS, and Windows (WSL). See all options with | bash -s -- --help, or read the feeding guide.
